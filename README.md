# قدّها | QADHA

**فلوسك قرارك**

نموذج Web App عربي RTL لتعليم الوعي المالي من خلال مواقف وألعاب قصيرة مستوحاة من الحياة اليومية في مصر. المشروع مصمم للعرض في مسابقة جامعية ويستخدم بيانات وأموالًا افتراضية بالكامل.

## تشغيل المشروع

لا يحتاج المشروع إلى تثبيت حزم أو إنشاء حساب أو مفتاح API.

### الطريقة الأسرع على Windows

1. افتحي PowerShell داخل مجلد `qadha`.
2. شغّلي خادمًا محليًا بسيطًا:

```powershell
python -m http.server 4173
```

3. افتحي المتصفح على:

```text
http://127.0.0.1:4173
```

إذا كان أمر `python` غير متاح، يمكن استخدام أي خادم ملفات ثابت أو فتح `index.html` مباشرة. الخادم المحلي هو الخيار المفضل للعرض.

## رحلة العرض المقترحة

1. ابدئي من شاشة الترحيب واختاري **ابدئي رحلتك**.
2. مرّي سريعًا على onboarding واكتبي اسمًا مستعارًا.
3. اشرحي بطاقة المستوى والتحدي اليومي في الرئيسية.
4. افتحي **صيدة النصاب** وأجيبي على موقف واحد.
5. اعرضي **تحدي آخر الشهر** وتوزيع الميزانية.
6. افتحي **ازرعي هدفك** ووضحي حساب وقت الوصول للهدف.
7. اختمي بالمكتبة، الأوسمة، و**الجمعية الذكية**.
8. من الإعدادات استخدمي **إعادة التجربة** قبل أي عرض جديد.

## ما تم تنفيذه

- شاشة ترحيب وهوية بصرية كاملة.
- onboarding من أربع خطوات من دون بيانات حساسة.
- لوحة رئيسية responsive بالعربية RTL.
- ثلاث ألعاب كاملة، خمس سيناريوهات لكل لعبة.
- توزيع ميزانية تفاعلي يمنع تجاوز المبلغ المتاح.
- كشف احتيال مع إشارات الخطر وإرشادات التحقق الآمن.
- حاسبة هدف ادخار وموعد وصول تقديري.
- نتيجة فورية وشرح بعد كل قرار.
- XP وخمسة مستويات وستة أوسمة.
- تحدٍ يومي وتتبّع للدقة والإنجازات.
- مكتبة من ستة دروس مع mini quiz لكل درس.
- هدف ادخار افتراضي ومحاكاة جمعية جماعية.
- تعديل الاسم المستعار والرمز.
- حفظ LocalStorage مع قيم آمنة عند فساد البيانات.
- منع تكرار XP عند إعادة الألعاب، مع مكافأة تحسين أفضل نتيجة فقط.
- إعدادات، تقليل حركة، مساعدة، وإعادة بيانات العرض بتأكيد.
- تصميم mobile-first مع bottom navigation وsidebar للديسكتوب.

## خصائص لم تُنفّذ عمدًا

- تسجيل حسابات حقيقية أو التحقق من الهوية.
- ربط بنوك أو محافظ أو بطاقات أو بوابات دفع.
- تحويلات، إيداعات، سحب، التزامات جمعية أو أرصدة حقيقية.
- نصائح مالية أو استثمارية شخصية.
- Backend أو قاعدة بيانات أو مزامنة سحابية.
- إحصاءات سوقية أو وعود أثر لم يتم قياسها.

## تنبيه تعليمي

قدّها منصة تعليمية تجريبية. المحتوى للتوعية والتعلم فقط، ولا يمثل نصيحة مالية أو استثمارية أو بديلاً عن التواصل مع الجهات المالية الرسمية. الرسوم والشروط والأهلية تختلف بين مقدمي الخدمات ويجب مراجعتها من المصادر الرسمية.
